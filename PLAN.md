# Snack Tally — План реализации

> «Count snacks, not grams.»
> Перекусы считаются штуками (горсть, долька, печенье); приложение учит, сколько
> калорий в твоей горсти, что тебе действительно «стоило того» и когда обычно
> тянет перекусить, — и строит план перекусов на остаток дня.

## 0. Архитектура и разрешения

Полностью локальное, `expo-sqlite`. `expo-notifications` удалён (не нужен),
`VIBRATE` — лёгкая вибрация, выключается в Settings. INTERNET и всё
чувствительное — в `blockedPermissions`.

## 2. Модель данных

| Таблица | Поля |
|---|---|
| snacks | id, name, cat, unit, label_kcal, archived |
| logs | id, day, minute, snack_id, pieces, kcal (снимок модели порции), rating 1–5 |
| checks | id, snack_id, day, kcal — взвешенная порция |
| model | key (portion:id / taste:id / cat:cat / pace / paceDay), json — накопленное состояние |
| settings | budget, target 0.7/0.8/0.9, flex, haptics, pins:<day>, flex:<day>, model_version |

## 3. Движок (`src/lib`)

- `models.ts` — три накапливаемые модели: порция (проверки с забыванием 0.85
  поверх этикетки с весом 2, разброс стянут к 25%), вкус (оценки с забыванием,
  сжатие к виду и к 3.4), темп (гамма-пуассон по 12 двухчасовым окнам,
  обновляется по каждому закрытому дню с записями, забывание 0.95).
- `forecast.ts` — конец дня: съеденное (среднее ± разброс порций) + составной
  Пуассон по оставшимся окнам → шанс уложиться (нормальное приближение).
- `planner.ts` — точное ДП: окно × занятый бюджет (шаг 5 ккал) × прошлый перекус;
  ценность = (вкус − 3) × убывающая отдача штук × «окно тяги»; каждый перекус
  резервирует среднее + z·разброс порции; одно окно — один перекус, без повторов
  подряд. Сверено полным перебором в тестах.
- `conflicts.ts` — «хочу X» не влезает: дефицит с долей запаса на неуверенность и
  альтернативы, проверенные перерешиванием (флекс недели, меньше штук, похожий
  перекус того же вида, «сначала проверь порцию»); сравнение планов для what-if.

## 4. Экраны (6)

`index` (циферблат, следующий по плану, лента дня), `pantry` (кладовая),
`snack/[id]` (деталь перекуса), `plan` (Plan / What if), `stats`, `settings`.
